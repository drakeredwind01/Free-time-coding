Sound sources for the SDPY talk timer (end / warning cues)

All pulled from Freesound.org preview streams (public, no login required to stream;
account needed only for the "original quality" download, which we don't need for a
short UI cue). `raw/` = untouched preview downloads. `trimmed/` = first 4s + 0.7s
fade-out, ready to use as a UI sound.
